# VelvetFeed

Mobile-first installable PWA with full-screen swipe feed, favorites, video imports, direct video URLs, and offline application shell.

## Deployment

GitHub Actions publishes the static app to GitHub Pages. Enable **Settings → Pages → Build and deployment → Source: GitHub Actions**. The repository is currently private; Pages availability depends on your GitHub plan and repository settings.

## Limitations

RedGIFs integration is not yet implemented. Demo content is used. Local video imports last only for the current browser session; favorites and direct URLs persist in localStorage. Remote videos are not cached offline.
